# Crédits

GEARSTORM: Boss Circuit est un jeu original créé pour ce projet.

- Direction et univers : projet GEARSTORM.
- Moteur, gameplay et interface : HTML5 Canvas, JavaScript et Web Audio.
- Key art original : généré avec OpenAI Image Generation pour ce projet, sans texte ni élément de franchise existante.
- Icône d’application originale : générée avec OpenAI Image Generation puis déclinée en formats PWA 192 et 512 px.
- Polices : pile système locale, aucune police distante.
- Bibliothèques et assets tiers : aucun au runtime.

Tous les personnages, machines et noms de GEARSTORM sont originaux.
